# Vrinda Store Annual Report

## Overview

This dashboard presents an annual performance view for Vrinda Store, including monthly order and sales trends, customer gender split, order status distribution, top-performing states, sales channel share, and age/gender order patterns.

## Key Features

- Monthly comparison of order count and sales amount.
- Gender split analysis for sales performance.
- Order status breakdown to highlight delivered, returned, cancelled, and refunded activity.
- Top states ranking by sales value.
- Channel distribution for marketplace performance.
- Age vs gender order mix across adult, senior, and teenager segments.

## Project Structure

- `Excel Workbook/` — Source data files used to build the dashboard.
- `Dashboard (2).png` — Current dashboard screenshot shown below.
- `README.md` — Project documentation and summary.

## Benefits

- Provides a clear annual summary for strategic review.
- Helps identify the best-performing sales channels and states.
- Reveals customer demographics and order quality through delivery performance.
- Supports decision-making for marketing, inventory, and channel investment.
